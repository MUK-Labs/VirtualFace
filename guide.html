The two layouts

Vogel’s 1968 drawing

Martin Vogel of the University of Bonn published a keyboard design in Die Zukunft der Musik in 1968. The layout puts fifths, thirds and septimal intervals in recurring positions around the larger keys. Ulf-Diether Soyka reproduced the drawing in the work report for his Third Symphony. VirtualFace transcribes its 145 labeled positions. See the drawing on page 5 or play the Vogel layout.

Stamm’s built manual

Hans-André Stamm commissioned the organ in 1978 while studying in Bonn. Schumacher built it in Eupen in 1979 from Vogel’s plans. The console has a special upper manual, two conventional manuals that can each be assigned a selection of twelve pitches, and a pedalboard. The special manual gives direct access to the organ’s just-intonation pitches. Stamm specifies 48 tones per octave and 328 pipes. Stamm on the commission · Stamm’s technical description · Schumacher’s instrument record

Stamm describes eight staggered rows, placed a whole tone apart, so the same fingering can be reused in different tonalities. He documents the addition of MIDI during the 1994–99 loan to the Royal Conservatory in The Hague. Soyka reports working with the organ from 2006 and recording with it at Vienna’s Prayner-Konservatorium. Stamm’s account · Soyka’s report and console photo

Tuning and notation

Just intonation expresses an interval as a frequency ratio. A pure fifth is 3/2, a pure major third is 5/4, and a harmonic seventh is 7/4. VirtualFace uses the German pitch name h for B natural and b for B-flat.

  • A numbered superscript such as ⁻¹ lowers the note by one syntonic comma (81/80, about 21.51 cents). ⁺¹ raises it by the same amount.
  • A sign on the same line as the note name marks a septimal comma (64/63, about 27.26 cents). For example, b− lowers the Pythagorean B-flat (16/9) to 7/4 above C.

VirtualFace sets the reference C to MIDI note 60 in standard tuning, about 261.63 Hz. The sine tone and tuned MIDI output use the same nominal ratios, with register inferred from the layout. The organ’s actual key-to-pipe assignments and measured frequencies remain unverified.

MIDI setup

Raw key addresses and MIDI input

Each playable position has a raw MIDI note number and a channel offset. The selected input or output base channel determines where that layout’s first channel starts. Change the base channel to move the entire block. Channels wrap from 16 back to 1, while the note numbers stay fixed.

Stamm1–8Positional assignments. The edge revisions left gaps so retained keys could keep their existing addresses. The restored walnut halves use channel 8, notes 111–114.

For example, the reference C in the Vogel layout is channel 1, note 44. The corresponding two walnut halves in the Stamm layout are channel 4, notes 120 and 121. If Stamm’s base channel is set to 15, both halves move to channel 2. They share a reference pitch, so either half sends note 60 in tuned mode.

Raw key addresses sends these pairs on press and release for recording gestures or driving a custom patch. MIDI input uses raw addresses for the selected layout in either output mode, with an independent input base channel. Incoming Note On and Note Off light and release the keys. Browser audio and outgoing MIDI respond to local playing. The app’s raw addresses are specific to VirtualFace, and the physical organ’s hardware MIDI map remains unverified.

Note + pitch bend

This output format sends the nearest standard MIDI note with a pitch bend for the remaining offset. Set the receiving instrument’s bend range to match VirtualFace. The default is ±2 semitones. For a key at ratio r relative to reference C, the target is 60 + 12 log₂(r) in MIDI semitones. VirtualFace rounds to the nearest MIDI note and sends the fractional difference as pitch bend before Note On. MIDI 1.0 message reference

  • Multiple channels gives each held note its own channel so chords can contain separate bends. The receiving instrument or DAW must preserve those channel-specific bends. VirtualFace rotates through up to 15 channels, skipping channel 10.
  • Single channel sends one held note at a time on the selected output channel.

Use Release all notes in the MIDI panel to clear held notes and highlights.
